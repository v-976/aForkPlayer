ForkPlayer · проверка настоящего FXML-портала

Только fxmlparsers.in.net. Никаких демонстрационных видео или посторонних каталогов. Запросы выполняются непосредственно из Safari.

Результат
Нажмите «Проверить подключение».
Ошибка CORS и сетевой сбой могут выглядеть одинаково для JavaScript. Точную причину без серверных заголовков определить нельзя. Видео не запускается, персональные данные не отправляются.
